# FamilyLink Plus (부모-자녀 안드로이드 스마트폰 통합 제어 시스템)

기존 구글 패밀리 링크(Family Link)로는 알 수 없었던 **브라우저 방문 웹페이지(URL·검색어) 및 유튜브 시청 영상 제목**, **위치 기록과 앱 사용 기록의 지도 위 동시 확인(예: "학교앞 편의점에서 유튜브 30분 사용")**, **30분(수정 가능) 주기 부모 알림**, **사용 시간대(오전 10시~오후 9시) 및 앱별 제어**, **우회/삭제 방지(`TamperGuard`)**를 제공하는 안드로이드 네이티브(Kotlin + Jetpack Compose) 솔루션입니다.

---

## ✨ 주요 기능 요약

1. **브라우저 웹페이지 & 유튜브 시청 기록 (4.1 & 4.6)**
   - Chrome, 삼성 인터넷, 네이버 웨일, Firefox, Edge에서 방문한 **웹페이지 URL·페이지 제목·검색어** 기록
   - YouTube 일반 영상 및 Shorts **시청 영상 제목** 실시간 기록 (주소창 타이핑 중 미완성 문자열 자동 필터링)
2. **위치 기록 + 앱 사용 기록 지도 동시 확인 (4.2)**
   - 자녀가 반경 50m 이내에서 3분 이상 머무른 **체류 지점(Stay-Point)**과 그 시간 동안 실행한 **앱 사용 시간·방문 웹페이지**를 자동 병합
   - 지도 마커에 **`📍 역삼초 앞 GS25 편의점 · YouTube 30분, Chrome 10분`** 형태로 직관적 표시 및 탭 시 상세 내역 제공
3. **사용 가능 시간대 & 일일 총 사용시간 제한 (4.3 & 4.6)**
   - 기본 **오전 10:00 ~ 오후 9:00 (`10:00 ~ 21:00`)** 사용 시간대 설정 (자유 변경 가능)
   - 허용 시간대 안이라도 하루 총 사용시간(예: 120분) 초과 시 자동 잠금
4. **사용 가능한 앱 정의 (4.4)**
   - 앱별로 **`상시 허용`**(전화·문자·EBS 등) / **`시간 내 허용`**(일일 개별 한도 설정 가능) / **`차단`**(게임 등) 지정
5. **사용 시간 30분마다 부모 알림 (4.5)**
   - 기본 **30분**(10분/15분/30분/45분/60분 또는 5~180분 직접 입력 수정 가능)마다 누적 사용 시간, 현재 위치 상호명, 최근 주로 사용한 앱 요약을 부모에게 알림
6. **스마트폰 제어 필수 부가 기능 (4.6)**
   - **원격 즉시 잠금 & 보너스 시간 부여**: 부모 앱에서 버튼 하나로 *'지금 즉시 잠금'* 또는 *'+15분 / +30분 보너스 시간'* 부여
   - **우회 및 삭제 방지 (`TamperGuard`)**: 기기 관리자 등록으로 삭제 차단 + 자녀가 `설정`에서 접근성 해제/강제종료/시간변경 진입 시 즉시 부모 PIN 잠금 화면 표시
   - **안심존(Geofencing) & 단말기 상태 모니터링**: 집·학교·학원 반경 진·출입 알림 및 배터리 잔량, 벨소리/진동/무음 상태, Wi-Fi/데이터 상태 실시간 확인

## 🛠️ 1. APK 빌드 방법

프로젝트 루트 폴더(`/Users/anjaemo/Documents/Code/familylink`)에서 아래 명령어를 실행하면 전체 단위 테스트 검증과 함께 부모용/자녀용 APK 2개가 생성됩니다.

```bash
./gradlew testDebugUnitTest assembleDebug
```

빌드가 완료되면 다음 경로에 APK 파일이 생성됩니다:
- **부모용 APK**: `app-parent/build/outputs/apk/debug/app-parent-debug.apk`
- **자녀용 APK**: `app-child/build/outputs/apk/debug/app-child-debug.apk`

## 📲 2. 스마트폰 설치 및 초기 권한 설정 방법

### A. 부모님 스마트폰에 설치하기
1. 부모님 안드로이드 폰을 맥(Mac)에 USB 케이블로 연결(USB 디버깅 허용)하거나, `app-parent-debug.apk` 파일을 카카오톡/파일전송으로 부모 폰에 보낸 뒤 설치합니다.
2. 맥 터미널에서 바로 설치하려면 아래 명령어를 실행합니다:
   ```bash
   adb install -r app-parent/build/outputs/apk/debug/app-parent-debug.apk
   ```

### B. 자녀 스마트폰 원클릭 설치 및 보호 권한 설정 (ADB 권장 ⭐)
자녀용 앱은 크롬 주소창 읽기, 앱 사용시간 측정, 잠금 오버레이 표시, 임의 삭제 방지를 위해 4가지 시스템 권한이 필요합니다. **맥(Mac)과 자녀 폰을 USB로 연결해 스크립트를 1회 실행하면 APK 설치부터 모든 권한 부여까지 한 번에 자동 완료**됩니다.

#### [Step 1] 자녀 스마트폰에서 'USB 디버깅' 켜기
1. 자녀 폰의 **설정 → 휴대전화 정보 → 소프트웨어 정보**로 이동합니다.
2. **빌드번호**를 연속으로 **7번 터치**하여 `개발자 옵션`을 활성화합니다.
3. **설정 → 개발자 옵션**으로 들어가서 **USB 디버깅**을 켭니다.

#### [Step 2] 자녀 스마트폰을 맥(Mac)에 USB 케이블로 연결
1. 케이블을 연결하면 자녀 폰 화면에 **"USB 디버깅을 허용하시겠습니까?"** 팝업이 뜹니다.
2. **"이 컴퓨터에서 항상 허용"**에 체크하고 **허용**을 누릅니다.

#### [Step 3] 맥(Mac) 터미널에서 원클릭 스크립트 실행
맥 터미널에서 아래 명령어를 실행합니다:

```bash
./scripts/setup-child-device.sh
```

이 스크립트가 자동으로 수행하는 작업:
- `[0/5]` 연결된 자녀 안드로이드 단말 확인 및 `app-child-debug.apk` 자동 설치
- `[1/5]` 사용정보 접근 권한(`GET_USAGE_STATS`) 및 다른 앱 위에 표시(`SYSTEM_ALERT_WINDOW`) 허용
- `[2/5]` 정밀 위치·백그라운드 위치(`ACCESS_BACKGROUND_LOCATION`) 및 알림 권한 허용
- `[3/5]` 접근성 서비스(`ChildAccessibilityService`) 자동 활성화
- `[4/5]` 기기 관리자(`ChildDeviceAdminReceiver`) 및 삭제 방지(`Device Owner`) 등록
- `[5/5]` 배터리 최적화 예외 등록 (백그라운드 강제종료 방지)

#### [Step 4] 마무리 (개발자 옵션 끄기)
- 스크립트 실행이 완료되면 자녀가 개발자 옵션을 건드리지 못하도록 자녀 폰의 **설정 → 개발자 옵션** 스위치를 다시 **끔(Off)**으로 변경하고 USB 케이블을 분리합니다.

> 💡 **PC 없이 자녀 폰 화면에서 직접 설정하는 방법**:
> `app-child-debug.apk`를 직접 설치해 실행하면 대시보드에 **[1. 접근성 서비스]**, **[2. 사용정보 접근 권한]**, **[3. 다른 앱 위에 표시]**, **[4. 기기 관리자 활성화]** 버튼 4개가 표시됩니다. 각 버튼을 눌러 설정 화면으로 이동한 뒤 차례대로 켜주셔도 동일하게 동작합니다.

## 📖 3. 앱 화면별 상세 사용법

### 👨‍👩‍👧 부모용 앱 (`FamilyLink Plus 부모용`)

상단 상태 바에는 자녀 폰의 **현재 체류 장소, 현재 실행 중인 앱, 배터리 잔량(%), 소리 모드(벨소리/진동/무음), 네트워크 상태(Wi-Fi/데이터), 오늘 총 사용시간**이 상시 표시됩니다. 하단 4개 탭으로 모든 기능을 제어합니다.

#### ① `🗺️ 위치+사용지도` 탭 (기능 4.2)
- 지도 위에 자녀의 이동 경로와 체류 지점 마커가 **`📍 역삼초 앞 GS25 편의점 · YouTube 30분`** 형태의 배지로 표시됩니다.
- 지도 위 배지나 하단 장소 칩을 터치하면:
  - 해당 장소에 머무른 시간대(예: `15:10 ~ 15:50, 40분 체류`)와 상세 주소
  - **그 장소에서 사용한 앱별 시간 막대그래프** (예: YouTube 30분, Chrome 10분)
  - **그 장소에서 본 크롬 웹페이지 및 유튜브 영상 목록**을 한 화면에서 동시에 확인할 수 있습니다.

#### ② `🌐 웹·유튜브` 탭 (기능 4.1 & 4.6)
- 자녀가 크롬·삼성 인터넷·웨일 등에서 접속한 **웹페이지 제목과 전체 URL**, **검색어**, 그리고 **YouTube 일반 영상 및 Shorts 시청 제목**이 시간순으로 기록됩니다.
- 상단 검색창에서 키워드(예: `마인크래프트`, `편의점`)로 검색하거나, `웹페이지` / `검색어` / `YouTube 영상` / `YouTube 쇼츠` 칩으로 필터링할 수 있습니다.
- 각 기록마다 **어느 장소(`📍 역삼초 앞 GS25 편의점`)에서 몇 분 동안 보았는지** 함께 표시됩니다.

#### ③ `⏰ 시간·앱 제어` 탭 (기능 4.3, 4.4, 4.5, 4.6)
- **원격 즉시 잠금 / 보너스 시간 부여**:
  - 상단 스위치를 켜면 허용 시간대 여부와 관계없이 자녀 폰이 즉시 잠깁니다(전화·문자만 가능).
  - **`+15분 부여`**, **`+30분 부여`** 버튼을 누르면 오늘 사용 가능한 시간이 즉시 연장되고 잠금이 해제됩니다.
- **사용 가능 시간대 정의 (기본 `10:00 ~ 21:00`)**:
  - 시작 시/분, 종료 시/분을 입력하고 **[시간대 저장]**을 누르면 해당 시간 외에는 자녀 폰이 자동으로 잠깁니다.
  - 하단 칩(`하루 60분`, `90분`, `120분`, `180분`, `240분`)으로 일일 총 사용시간 한도를 설정할 수 있습니다.
- **사용 시간 주기별 부모 알림 설정 (기본 `30분마다`)**:
  - `10분` / `15분` / `30분` / `45분` / `60분` / `90분` 칩을 선택하거나 원하는 분(5~180분)을 직접 입력해 **[주기 적용]**을 누르면 해당 주기마다 부모 폰으로 사용 현황 알림이 발송됩니다.
- **사용 가능한 앱 정의**:
  - 설치된 각 앱을 **`상시 허용`**(잠금 중에도 허용) / **`시간 내 허용`**(허용 시간대 및 일일 한도 내 허용) / **`차단`**(항상 실행 불가)으로 설정할 수 있습니다.

#### ④ `🔔 30분알림·안심존` 탭 (기능 4.5 & 4.6)
- **실시간 알림 내역**: 30분 주기 누적 사용 알림, 안심존 진입/이탈 알림, 자녀의 설정/권한 변경(우회) 차단 알림, 자녀의 보너스 시간 요청 알림을 모아 봅니다.
  - 우측 상단 **`[+30분 알림 테스트]`** 버튼을 누르면 실제 안드로이드 상단 시스템 푸시 알림이 어떻게 도착하는지 즉시 체험할 수 있습니다.
- **안심존(Geofencing) 관리**:
  - 집, 학교, 학원 등의 이름과 반경(m)을 추가/삭제하여 자녀가 도착하거나 이탈할 때 즉시 알림을 받습니다.

### 👦 자녀용 앱 (`FamilyLink Plus 자녀용`)

1. **평상시 화면 (대시보드)**
   - 오늘 남은 사용 시간, 약속된 사용 가능 시간대(`10:00 ~ 21:00`), 앱별 허용 상태 및 오늘 사용 시간을 확인할 수 있습니다.
   - 시간이 부족할 때 **`[부모님께 +15분 요청]`** 버튼을 누르면 부모님 앱으로 보너스 시간 요청 알림이 전송됩니다.
2. **차단/잠금 오버레이 화면 (`LockOverlayScreen`)**
   - 사용 가능 시간대(`10:00 ~ 21:00`) 외의 시간, 일일 한도 초과, 차단된 앱 실행, 부모님의 즉시 잠금, 또는 안드로이드 `설정`에서 접근성/기기관리자 해제를 시도할 경우 즉시 전체 화면 잠금이 작동합니다.
   - 잠금 상태에서도 **`[📞 긴급 전화]`** 버튼이나 상시 허용 앱(전화·문자)은 사용할 수 있습니다.
   - 부모님이 직접 잠금을 풀어야 할 때는 **부모님 PIN 번호(초기 비밀번호: `0000`)**를 입력하면 즉시 잠금이 해제되고 15분이 부여됩니다.
