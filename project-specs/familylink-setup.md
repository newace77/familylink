# FamilyLink Plus Project Specification

본 문서는 `docs/superpowers/specs/2026-10-17-familylink-plus-design.md`와 동일한 프로젝트 명세서입니다.

## 핵심 요구사항 요약
1. **아이의 스마트폰을 제어할 수 있는 앱** (`:app-parent`, `:app-child` 분리형 APK)
2. **부모 : 안드로이드, 자녀 : 안드로이드** (Kotlin + Jetpack Compose, Min SDK 26, Target SDK 34)
3. **기존 패밀리 링크의 한계 극복**: 상세 앱 사용 맥락 및 조회한 웹페이지/유튜브 시청 내역 확인
4. **중요 기능**:
   - **4.1**: 크롬, 삼성 인터넷, 웨일 등 브라우저에서 조회한 페이지(URL + 제목) 및 유튜브 시청 영상 제목 기록
   - **4.2**: 위치 기록(체류 지점)과 앱 사용 기록을 지도에서 동시에 확인 (예: "학교앞 편의점에서 유튜브 앱 30분 사용")
   - **4.3**: 사용 시간대 정의 (기본 오전 10시 ~ 오후 9시, 요일별 설정 및 일일 총 사용시간 제한)
   - **4.4**: 사용 가능한 앱 정의 (`ALWAYS_ALLOWED` 상시 허용 / `ALLOWED` 시간대 내 허용 및 개별 시간 제한 / `BLOCKED` 차단)
   - **4.5**: 사용 시간 30분마다 부모에게 푸시 알림 (30분 주기는 10분~120분 등 자유 수정 가능, 현재 위치 및 주요 사용 앱 요약 포함)
   - **4.6**: 추가 필수 제어 기능
     - 우회 및 삭제 방지 (`DeviceAdminReceiver`, 설정 앱 내 접근성/강제종료 진입 시 PIN 잠금 오버레이, ADB Device Owner 설정 스크립트)
     - 원격 즉시 잠금 및 보너스 시간(+15분/+30분/+60분) 부여
     - 안심존(집·학교·학원 지오펜싱) 진·출입 알림
     - 자녀 단말기 상태 모니터링 (배터리 잔량/충전, 벨소리/진동/무음 모드, Wi-Fi/데이터 상태, 권한 정상 여부)
